# Glira Bharat — Standalone Enterprise ERP, CRM, Billing & E-Commerce Suite

A complete, zero-dependency, offline-first single-page enterprise software suite built with **HTML5, CSS3, and Vanilla JavaScript**. Designed to run directly from a Git repository or static host (GitHub Pages, Hostinger, Netlify, or local browser) without requiring Node.js, Python, or external database setup.

## Preloaded Sample Dataset (390+ Realistic Records)
- **CRM & Customers (`70 rows`)**: Enterprise, SMB, D2C VIP, and Wholesale accounts with LTV, order counts, and segment filters.
- **Leads & Sales Pipeline (`65 rows`)**: Full lead scoring, deal value tracking, Table & Kanban board views, and one-click **Convert to Customer**.
- **Billing & GST Invoices (`75 rows`)**: Subtotal, 18% GST calculation, Paid/Pending/Overdue tracking, and printable Tax Invoice preview.
- **Products & Inventory (`65 rows`)**: Multi-warehouse SKUs, unit cost vs. selling price, low-stock reorder alerts, and one-click restocking.
- **Marketing Campaigns (`55 rows`)**: Multi-channel spend vs. budget, impressions, CTR, conversions, and live ROAS analytics.
- **E-Commerce Storefront & Orders (`60 rows`)**: Live D2C storefront catalog with shopping cart checkout that automatically deducts inventory stock and generates a Paid GST Invoice.

## Git Repository & Local Deployment
```bash
git clone <your-repo-url>
cd glira_bharat_erp_suite
# Open index.html directly in any browser, or serve with any static server:
npx serve .
```
